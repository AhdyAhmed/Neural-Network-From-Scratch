# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-12

### Added

- A NumPy-only sequential neural-network API with dense and dropout layers.
- ReLU, sigmoid, tanh, and numerically stable softmax activations.
- MSE, binary cross-entropy, and categorical cross-entropy losses.
- SGD, Momentum, RMSProp, and Adam optimizers.
- Xavier and He initializers, L2 regularization, early stopping, and diagnostics.
- Reproducible examples for regression, classification, MNIST, and controlled ablations.
- Numerical gradient checking, metrics, visualization helpers, and a comprehensive test suite.
- GitHub Actions testing on Python 3.10 through 3.13.
